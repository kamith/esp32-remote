Pair this phone

This page controls one ESP32 board, and it needs that board's key first. You only do this once.

  1. At home, on the same WiFi as the board, open http://esp32.local.
  2. Under Remote control, tap Set up phone remote.
  3. Scan the QR code with this phone, or open the link on it.

After that, this page works on any network, including mobile data.
